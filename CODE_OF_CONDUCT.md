# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Resumo

Participe de forma respeitosa. Não são tolerados assédio, ataque pessoal, discurso de ódio, exposição de dado privado de outra pessoa ou qualquer conduta que uma pessoa razoável consideraria inadequada em ambiente profissional.

## Especificidade deste projeto

O assunto aqui é política, então divergência é esperada e faz parte. A linha é clara: discuta o dado, a fonte e o texto, nunca a pessoa que contribuiu.

Uso do repositório para propaganda de partido, campanha ou candidato é violação e leva a remoção.

## Como reportar

Envie um relato pela aba Security ou por issue privada. Relatos são tratados de forma confidencial e respondidos em até sete dias.

Consequências vão de advertência a banimento permanente, conforme a gravidade e a reincidência.
